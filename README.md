# React Vite Starter

This is a React (19.x) + Vite (8.x) + Typescript (5.x) template repository, preinstalled with the following dependencies:

- Routing: @tanstack/react-router
- Styling: tailwindcss
- State management: zustand
- Icons: lucide-react
- Testing: @testing-library/react + vitest + jsdom
- Code formatting: eslint + prettier
